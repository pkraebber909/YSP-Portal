# Logo batches 9–11

The reattached Batch 8 archive has the same SHA-256 as the Batch 8 archive
already imported, so it was skipped. Batches 9, 10 and 11 contain 11, 30 and
6 confirmed image files. All 47 were matched to existing CRM club IDs with
empty logo slots. The original bytes, aspect ratios, backgrounds and
transparency were retained.

Four additional source rows document reused marks. West Babylon SC uses the
existing South Shore Soccer Club asset, and Green Warriors SA uses the
existing Green Warriors Soccer asset. Auburndale SC is the same existing CRM
record as the qualified Auburndale SC (LIJSL) image assignment. Freeport PAL
(LIJSL) is covered by the existing Freeport PAL record and asset. No records
were created or merged, and no existing logo was replaced.

The 49 new logo assignments use the CRM seed's `logo_path IS NULL` guard, so
staff-selected logos remain intact. No partnership, ownership, contact,
source, note or action data was changed. The package review lists contain 31,
33 and 47 entries without included images; those entries remain unchanged.
Several supplied files are small source images and should stay at small web
display sizes.

See [`logo-reconciliation-batches-09-11.json`](logo-reconciliation-batches-09-11.json)
for every source URL, filename, native size, hash, matching ID, decision,
documented alias, and review-list entry. The JSON also records the duplicate
Batch 8 archive hash.
